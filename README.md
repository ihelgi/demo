# Aura · demo

Demo statica della dashboard **Aura**: temperatura e umidità di casa, grafico combinato e METAR/TAF.

- Sito: <https://ihelgi.github.io/demo/>
- Dati: istantanea **di esempio** (sintetica) in `data-1.json`, `data-7.json` e `data-30.json` per 24 ore, 7 giorni e 30 giorni. Non sono dati live.
- Pubblicazione: GitHub Pages dal branch `main`, root del repository.
- Aggiornamento: sostituire i tre JSON con un nuovo export mantenendo la stessa struttura, poi fare commit e push.

File: `index.html`, `chart.umd.min.js`, `manifest.webmanifest`, icone e i tre file dati.
